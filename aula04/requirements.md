Sistema escolhido:

WhatsApp

Regras de Negócio (3)
RN 1:Apenas usuarios com numero de telefone valido podem criar uma conta.

RN 2:Um numero de telefone só pode estar vinculado a uma conta por vez

RN 3:O usuario bloqueado nao pode mandar mensagens para quem o bloqueou

Requisitos Funcionais (3)
RF 1:O sistema deve permitir o envio de mensagens de texto

RF 2:O sistema deve permitir realizar chamadas de voz e video

RF 3:O sistema deve permitir o compartilhamento de fotos, videos e documentos

Requisitos Nao-Funcionais (2)
RNF 1:As mensagens devem ser entregues em poucos segundos.

RNF 2:o aplicativo deve funcionar em dispositivos android e IOS compativeis
